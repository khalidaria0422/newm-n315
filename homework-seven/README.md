# The Jungle Cook

Web 4: [Homework 7](https://in-info-web4.luddy.indianapolis.iu.edu/~karia/newm-n315/homework-seven)

## Instructions

- You must create the home and login page from the Jungle Cook prototype found [here](https://www.figma.com/design/f3cWuvIAGPB5qkG7J6aTNR/Jungle-Cook?node-id=1-2&t=4dxTpS5SblfgWqx3-1) or the Figma file found [here](https://www.figma.com/design/f3cWuvIAGPB5qkG7J6aTNR/Jungle-Cook?node-id=1-2&t=4dxTpS5SblfgWqx3-1).
- Your home and login page must look identical to the prototype in all media, meaning it must be responsive.
- When it is completely finished, you need to think about this being a fully dynamic site, so set it up accordingly.
- You must have the mobile menu working as well as the normal menu.
- Upload this to the web 4 server and Github and submit the Github link to this project.
