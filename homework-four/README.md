## Instructions

- Create a reusable JavaScript utility for displaying toast/alert messages. Create the CSS needed to style the different message types.

- Your notification utility should support different types of feedback such as:
  - Success
  - Error
  - Information
  - Loading/waiting

- Your website must contain at least **two pages** using the navigation/routing techniques we have already learned.

- Add a **Login/Sign** In button. Clicking the button should display a login form or modal containing at least an email and password field.

- Validate the login form before allowing it to submit. Your validation should check things such as:
  - Empty fields
  - Leading/trailing spaces
  - Minimum input length
  - A properly formatted email address containing @
  - Any other validation appropriate for the input

- When validation fails, display an **error notification** explaining what the user needs to correct.

- When the login is successful, display a **success notification** telling the user they have signed in.

- Include at least **one additional example of user feedback** somewhere in your site. For example, display a loading message while retrieving data and then notify the user when the data has loaded.

- Upload the completed project to the **Web 4** server and **GitHub**.

- Submit your **GitHub repository link** for grading.
